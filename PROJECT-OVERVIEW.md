# SC-500 Lab 2B: Secure Azure SQL Database

## Overview

This hands-on lab focused on securing an Azure SQL Database environment by addressing common security risks associated with identity, network exposure, database activity, and threat detection.

The lab involved securing the Azure SQL Database by strengthening administrative access, reducing unnecessary network exposure, establishing private connectivity, enabling database auditing, and improving protection against database threats.

The goal was to demonstrate how Azure security controls can be applied together to create a more secure and controlled SQL database environment.

## Security Problem Addressed

The SQL database environment required stronger protection against:

- Unnecessary public network exposure
- Broad network access
- Weakly controlled administrative access
- Lack of centralized database activity auditing
- Limited visibility into suspicious database activity

This lab addressed these risks using Microsoft Entra ID, Azure Private Endpoint, SQL Auditing, Log Analytics, and Microsoft Defender for SQL.

## Lab Focus

*Identity Security → Network Security → Database Auditing → Monitoring → Threat Protection*
